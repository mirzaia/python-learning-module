# Module 2: Learning Objectives

By the end of this module, you will be able to:

1. **Work fluently with Python collections**
   - Lists, dicts, sets, and tuples — when to use each
   - Nested data structures common in API responses
   - Slicing, unpacking, and membership testing

2. **Use comprehensions for concise data transformation**
   - List comprehensions instead of `for` loops
   - Dict comprehensions for building lookup tables
   - Filtering with `if` clauses inside comprehensions

3. **Transform API-style data structures**
   - Extract fields from nested dicts
   - Group and aggregate lists of records
   - Flatten, filter, and reshape data

4. **Apply functional patterns**
   - `map()`, `filter()`, `zip()`, `enumerate()`
   - `sorted()` with custom keys
   - Generator expressions for memory efficiency

## What This Module Does NOT Cover

- Type hints — Module 4 covers typing in depth
- pandas — Module 9 is dedicated to pandas
- Performance optimization — this is about fluency, not benchmarking
- Object-oriented patterns — classes are in Modules 4 and 8
