# Module 1: Learning Objectives

By the end of this module, you will be able to:

1. **Install and use `uv` as a Python package manager**
   - Initialize a project with `uv init`
   - Add and remove dependencies
   - Understand `pyproject.toml` structure

2. **Manage Python versions and virtual environments**
   - Set the Python version with `.python-version`
   - Create isolated environments with `uv sync`
   - Run commands inside the environment with `uv run`

3. **Structure a modern Python project**
   - Organize code into modules and packages
   - Use `__init__.py` for package initialization
   - Separate source code from tests and docs

4. **Run scripts and simple tests**
   - Execute Python scripts with `uv run`
   - Understand the difference between `python script.py` and `uv run python script.py`

## What This Module Does NOT Cover

- Advanced packaging or publishing to PyPI
- Docker or containerization — these come later
- Poetry, pipenv, or conda — we use `uv` throughout this learning path
- IDE setup — use whatever editor you prefer
