# Module 3: Learning Objectives

By the end of this module, you will be able to:

1. **Write pure functions with clear contracts**
   - Separate I/O from business logic
   - Write functions that are easy to test
   - Use default arguments and keyword arguments

2. **Handle errors with exceptions**
   - Raise `ValueError`, `TypeError`, and custom exceptions
   - Use `try/except/finally` for resource cleanup
   - Decide between returning an error value and raising

3. **Organize code into modules**
   - Split utility functions into separate files
   - Use `__init__.py` for package-level exports
   - Understand `if __name__ == "__main__"` guards

4. **Build reusable helper libraries**
   - Create a validation module used across exercises
   - Test error and success paths independently

## What This Module Does NOT Cover

- Async functions — Module 7
- Decorators in depth — introduced in Module 8 (FastAPI)
- Context managers (`with` statement internals) — used but not built here
- Class-based design — Modules 4 and 8
