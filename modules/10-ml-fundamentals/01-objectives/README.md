# Module 10: Learning Objectives

By the end of this module, you will be able to:

1. **Prepare data for machine learning**
   - Split data into train/test sets
   - Create feature matrices and label vectors
   - Handle categorical features with encoding

2. **Train and evaluate classifiers**
   - Logistic Regression and Random Forest
   - Compute accuracy, precision, recall, F1
   - Understand overfitting vs generalization

3. **Use scikit-learn pipelines**
   - Chain preprocessing and model steps
   - Avoid data leakage with `Pipeline`
   - Evaluate with cross-validation

4. **Interpret model results**
   - Read a confusion matrix
   - Understand feature importance
   - Set minimum performance thresholds

## What This Module Does NOT Cover

- Neural networks / deep learning — out of scope for v1
- Hyperparameter tuning (GridSearchCV) — mentioned but not required
- Model deployment and serialization — out of scope
- Regression models — classification focus
